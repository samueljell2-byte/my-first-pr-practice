# my-first-pr-practice

Practice repo for learning the GitHub PR workflow.

## Purpose

This repository exists to practice the end-to-end flow of contributing
to a project on GitHub: creating a branch, making a small change,
committing it, pushing, and opening a pull request.

## Workflow

1. Create a branch for your change.
2. Make a small, focused edit.
3. Commit with a clear message describing the change.
4. Push the branch and open a pull request.
5. Review and merge.
